# Emily's Nail Vault

This package must be published to a secure HTTPS address before iPhone photo upload and Home Screen installation will work reliably.

## Easiest route: Netlify Drop
1. Unzip this package on a computer.
2. Open Netlify Drop in a browser.
3. Drag the entire `emilys-nail-vault` folder into the upload area.
4. Open the generated web address in Safari on your iPhone.
5. Tap Share, then Add to Home Screen.

Photos and tags remain in Safari's local storage on that device. Clearing Safari website data can erase them.
